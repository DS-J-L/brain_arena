# 아틀라스의 형벌

세 거인이 든 판 위에 숫자 블록을 쌓는 2~4인 동시 제출 게임. 거인이 버티는 합을 넘겨 무너뜨린 플레이어가
그 거인이 든 블록 수만큼 벌점을 먹는다. 14라운드 후 벌점이 가장 낮은 사람이 이긴다.

## 1. 구성

| 항목 | 내용 |
| --- | --- |
| 인원 | 2~4명 |
| 거인 | 빨강·초록·파랑 3명. 각자 판 하나를 들고 있으며 처음에는 비어 있다 |
| 개인 블록 | 숫자 1~7 각 1개 |
| 개인 토큰 | 빨강·초록·파랑 각 2개 + 무지개 1개 (총 7개) |
| 라운드 | 14라운드. 제출 30초, 올릴 차례 결정 15초, 결과 표시 5초 |
| 보충 | 블록 7개·토큰 7개로 7라운드를 치르므로, **8라운드 시작 때 블록과 토큰을 처음처럼 새로 받는다** |

### 무너지는 한계 (인원별)

| 인원 | 버티는 합 | 무너짐 |
| --- | --- | --- |
| 2인 | 8까지 | 9 이상 |
| 3인 | 10까지 | 11 이상 |
| 4인 | 12까지 | 13 이상 |

한계는 게임 시작 인원으로 정하며, 도중에 누가 나가도 바뀌지 않는다.

## 2. 라운드 진행

1. **제출**: 모두 30초 안에 숫자 블록 1개 + 토큰 1개를 비공개로 낸다. 제출 후에는 바꿀 수 없다.
   미제출자는 남은 블록·토큰에서 무작위로 제출된다.
2. **공개**: 모두 제출하면 모든 제출(숫자·토큰)을 공개한다.
3. **올리기**: 큰 숫자부터 차례로 토큰 색의 거인 위에 올린다.
   - 같은 숫자끼리는 **선 플레이어부터 오른쪽(자리 순서)** 으로 올린다.
   - 무지개 토큰은 그 사람이 올릴 차례에 거인을 고른다.
4. **결과**: 5초 동안 보여 준 뒤 다음 라운드.

### 선 플레이어

- 첫 선은 무작위.
- 이후에는 **블록을 먹은 사람(거인을 무너뜨린 사람)** 이 선이 된다. 한 라운드에 여러 번 무너지면 마지막으로 먹은 사람.
- 아무도 먹지 않으면 선은 그대로.

### 패스

- 맨 먼저 올릴 사람은 패스할 수 있다(횟수 제한 없음).
- **첫 패스**: 다음으로 큰 숫자를 낸 사람부터 올리고, 패스한 사람은 맨 마지막에 올린다.
  예) 7·5·3·2 → 7이 패스 → 5·3·2·7
- **두 번째 패스**(새로 맨 앞이 된 사람의 패스): 작은 숫자부터(오름차순) 올린다. 이후 패스 불가.
  예) 5도 패스 → 2·3·5·7
- 순서가 바뀌지 않는 패스는 주지 않는다(2인전의 두 번째 패스 등).
- 결정 시간 15초가 지나면 패스하지 않고 올린다. 무지개 블록은 가장 안전한(벌점이 적은) 거인에 올린다.

## 3. 무너짐과 벌점

- 블록을 올린 직후 합이 한계를 넘으면 거인이 무너진다. 합이 한계와 같으면 버틴다.
- 그 블록을 올린 플레이어가 **거인이 들고 있던 블록 수(무너뜨린 블록 포함)** 만큼 벌점을 받는다.
- 원래 있던 블록은 치워지고, **무너뜨린 블록은 그 자리(거인 위)에 남는다.**
  - 예(2인): 3·4를 든 거인에 2를 올리면 합 9 → 무너짐, 벌점 3, 거인에는 [2]가 남는다.
- 같은 라운드의 남은 블록은 그 위에 이어서 올린다.
- 무너지지 않은 블록은 다음 라운드에도 남는다. 14라운드 후 남은 블록에는 벌점이 없다.

## 4. 승패

- 14라운드 종료 후 벌점이 가장 낮은 플레이어가 승리. 공동 최저면 무승부.
- 도중에 나간 플레이어는 게임에서 빠지고, 이번 라운드는 남은 사람만으로 처리한다. 한 명만 남으면 그 사람이 승리.

## 5. 공개 정보

| 공개 | 비공개 |
| --- | --- |
| 거인별 현재 블록과 합 | 다른 사람의 남은 블록과 토큰 |
| 모든 플레이어의 벌점, 선 플레이어 | 공개 전까지 이번 라운드에 다른 사람이 낸 블록·토큰 |
| 누가 이미 제출했는지 | 지난 라운드 기록 (게임이 끝난 뒤 전체 공개) |
| 공개 후 이번 라운드의 제출, 올린 순서, 패스한 사람 | |

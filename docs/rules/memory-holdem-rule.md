# 메모리 홀덤 규칙·구현 기준

수정일: 2026-11-11
상태: 서버 판정·게임 진행·화면·연습 봇(무작위 선택) 구현 완료.

16장의 위치를 30초 동안 기억하고, 나중에 공개되는 공용 카드 3장에 내 카드 2장을 더해 더 높은 포커 족보를 만드는 1대1 게임이다. **5판 3선승**으로 진행한다.

## 1. 경기 구성

- 한 판을 이기면 1승, 먼저 **3승**을 거둔 플레이어가 경기에서 승리한다.
- 두 패가 완전히 같은 판은 무승부로 승수에 넣지 않고 다음 판으로 넘어간다. 따라서 무승부가 나오면 판 수가 5판을 넘을 수 있다.
- 첫 판은 동전 던지기에서 이긴 플레이어가 `선공` 또는 `후공`을 고른다. 다음 판부터는 순서를 고를 권리를 판마다 교대한다.
- 판마다 조커를 뺀 52장을 새로 섞는다.

## 2. 한 판의 진행

| 단계 | 제한 시간 | 규칙 |
|---|---|---|
| 순서 선택 | 10초 | 선택권을 가진 플레이어가 선공·후공을 고른다. 시간 초과 시 무작위. |
| 암기 | 30초 | 16장을 4×4(A~P)로 공개한다. 두 사람은 같은 위치에서 같은 카드를 본다. |
| 카드 선택 | 장당 15초 | 보드를 뒤집고 남은 36장 중 3장을 공용 카드로 공개한다. 선공 1장 → 후공 2장 연속 → 선공 1장. 고른 칸은 즉시 잠기고 주인이 표시된다. 시간 초과 시 남은 카드 중 무작위 1장. |
| 결과 공개 | 8초 | 보드 전체와 두 사람의 5장(공용 3장 + 고른 2장) 족보를 공개한 뒤 다음 판으로 넘어간다. 3승째라면 공개가 끝난 뒤 경기 결과 화면으로 간다. |

## 3. 족보

스트레이트 플러시 → 포카드 → 풀하우스 → 플러시 → 스트레이트 → 트리플 → 투페어 → 원페어 → 하이카드. 로열 플러시는 가장 높은 스트레이트 플러시다.

같은 족보끼리는 족보를 이루는 숫자, 이어서 키커를 높은 순서대로 비교한다(투페어: 높은 페어 → 낮은 페어 → 키커, 풀하우스: 트리플 → 페어). `A-2-3-4-5`는 5가 가장 높은 스트레이트다. 무늬는 비교하지 않는다.

## 4. 구현 기준

- 덱, 배치, 단계 종료 시각, 선택 순서, 족보 판정은 서버(`memoryHoldemEngine.ts`)가 관리한다.
- 단계에 맞는 카드만 화면에 보낸다. 암기 중에는 보드 앞면만, 선택 중에는 공용 카드와 칸별 주인만, 결과 공개에서는 전부. 선택 단계에 재접속해도 보드 앞면은 내려가지 않는다.
- 카드 선택 요청은 화면이 보고 있던 판 번호와 선택 순번을 함께 보낸다. 서버는 현재 순번과 다르면 거절하므로 중복 요청이나 시간 초과 자동 선택과 겹친 클릭으로 두 장이 확정되지 않는다.
- 연습 봇은 카드를 기억하지 않고 남은 칸에서 무작위로 고른다.

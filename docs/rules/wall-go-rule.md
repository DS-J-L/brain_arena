# 벽바둑

7×7 판에서 말을 옮기고 그 말 옆에 벽을 세워, 내 말만 들어 있는 구역(땅)을 상대보다 넓게 만드는 1대1 게임.
현재는 **2인 기본형**만 구현한다. 공용 판정은 `packages/shared/src/wallGoRules.ts`, 진행은 `apps/server/src/games/wallGoEngine.ts`.

## 1. 구성

| 항목 | 내용 |
| --- | --- |
| 인원 | 2명. 선공(0번 자리, 파랑)은 무작위 |
| 판 | 7×7. 칸 이름은 열 A~G, 행 1~7 |
| 말 | 각자 4개. 2개는 지정 칸에서 시작, 2개는 빈칸에 배치 |
| 시작 칸 | 선공 B2·F6, 후공 F2·B6 (대각선으로 마주 봄) |
| 제한 시간 | 배치 20초, 이동 + 벽 45초 |

## 2. 진행

1. **배치**: 선공 → 후공 → 후공 → 선공 순서로 빈칸에 말을 하나씩 놓는다. 배치가 끝나면 선공부터 움직인다.
2. **이동**: 자기 말 하나를 상하좌우로 최대 2칸 옮긴다. 꺾어도 되고(오른쪽 1칸 → 위 1칸), 제자리(0칸)도 된다.
   벽·판 테두리를 넘거나, 다른 말이 있는 칸을 지나가거나 그 위에 멈출 수 없다.
3. **벽**: 이동을 마친 말이 선 칸의 위·아래·왼쪽·오른쪽 중 한 변에 벽을 반드시 하나 세운다.
   이미 벽이 있는 변과 판 테두리에는 세울 수 없다. 한 차례 = 이동 + 벽 하나(한 번에 전송).
4. 벽은 두 사람 모두를 막는다. 벽을 부수는 행동은 없다.
5. 시간이 지나면 둘 수 있는 수(배치는 빈칸) 가운데 하나를 무작위로 둔다.

## 3. 영역과 종료

- 벽(테두리 포함)으로 나뉜 구역에 **한 사람의 말만** 있으면 그 구역의 칸 전체가 그 사람의 땅이다.
  말이 있는 칸도 포함하고, 같은 구역의 여러 말은 중복해서 세지 않는다. 말이 없는 구역은 누구의 땅도 아니다.
- 매 수가 끝날 때 **어느 구역에도 두 사람의 말이 함께 있지 않으면** 즉시 끝난다. 각자 구역 안에 움직일 공간이 남아 있어도 끝난다.
- 땅의 합이 넓은 쪽이 이긴다. 같으면 **가장 큰 단일 영역**이 큰 쪽이 이기고, 그것도 같으면 무승부.
  (원래 규칙에서 동점 비교는 3인전 방송 규칙에 있던 것을 2인전에도 적용했다.)

## 4. 구현 메모

- 게임이 끝나지 않았다면 두 사람의 말이 함께 있는 구역이 있고, 그 구역은 2칸 이상이라 안의 말은 적어도 한 변이 열려 있다.
  그래서 0칸 이동 + 벽 하나가 항상 가능하며 패스 규칙이 필요 없다.
- 내부 변은 84개뿐이고 매 수마다 하나씩 막히므로 게임은 반드시 끝난다.
- 모든 정보가 공개된 게임이라 `getPlayerView()`는 두 사람에게 같은 화면을 보낸다.
- 행동에는 화면이 보던 `turn`을 실어 보내, 시간 초과 자동 수와 늦게 도착한 클릭이 겹치지 않게 한다.
- 연습 봇은 한 수 앞만 본다: 둔 뒤의 판에서 벽만 따라 센 거리로 내 말에 더 가까운 칸이 많은 수를 고르되, 가끔 차선을 둔다.

## 5. 아직 없는 것

- 3인전: 각자 말 2개, A → B → C → C → B → A 배치, 게임 중 한 번 이동 경로의 벽 하나를 부수고 지나가기.
